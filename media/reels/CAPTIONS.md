# Shelf Made reels: captions, hashtags, sound

Three vertical reels (1080×1920, 30 fps, ~20 s, mastered to −14 LUFS), each in two versions:

- `ReelN….mp4`: royalty-free music baked in, every cut on its beat. Post as-is.
- `ReelN…-game-sound.mp4`: the same edit with only the game's own sounds (till beeps, the
  truck, the alarm, thunder). Use it to add a trending song in Instagram's / TikTok's audio
  picker (keep the original sound at ~20–30 % so the beeps still come through).

Covers: `Cover1GlowUp.jpg`, `Cover2Restock.jpg`, `Cover3TierList.jpg` (the title sits in the
middle band, so it survives the profile grid's crop).

Suggested order: **Reel 3 first** (the tier list has the strongest comment bait), then Reel 1,
then Reel 2. One a day. Reply to every comment in the first hour, and pin a comment with the
link line.
